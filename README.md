These codes include the 2D toy examples of Data Driven BIP, the code 2Dw1DN.py is for training a sequential WGANgp for sampling the 2D prior, Trained_mupticase_example.ipynb is for testing the WGANgp, computing and viewing the posterior. The three "W1" file are for computing W1 and W2 distance vs training epochs, training samples and width of GAN. 
For higher dimensional Darcyflow PDE code, the WGANgp_train is for training WGANgp that generates MNIST image, the DARCY_MCMC is for running MCMC with the trained WGANgp and Darcyflow PDE solver to sample the posterior, the DARCY_MCMC_testing file is for viewing the sampling result.
